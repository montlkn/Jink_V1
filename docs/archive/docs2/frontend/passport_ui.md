# Frontend: Passport UI

## Summary
Visual interface for stamps, achievements, and memories. Must evoke curiosity and personal history.

## Layout
- Top: XP progress + total stamps
- Mid: Stamp grid or carousel
- Bottom: Tabs for Achievements and Lists

## Behavior
- Scroll reveals subtle orb parallax
- Each stamp tile: preview → detail view
- Memories: image, text, date

> *A collection should feel like a living atlas.*
