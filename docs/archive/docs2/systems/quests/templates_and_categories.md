# Quests: Templates and Categories

## Categories
- **Exploration:** visit buildings in new districts
- **Style:** find 3 Brutalist structures
- **Memory:** add 2 notes to past scans
- **Connection:** share a walk

## Template Schema
```
quest_id | name | type | xp_reward | target_count | expires_at
```

## Example
| Name | Type | Reward |
|------|------|---------|
| Morning Drift | Daily | 30 XP |
| Brutalist Bloom | Style | 60 XP |
| Archivist | Memory | 40 XP |

> *Every quest is a suggestion, not a command.*
