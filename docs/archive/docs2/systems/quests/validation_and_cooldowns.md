# Quests: Validation and Cooldowns

## Validation Rules
- All objectives validated server-side
- Prevent repeated completions on same scan
- XP granted only once per quest instance

## Cooldowns
| Type | Cooldown |
|------|-----------|
| Daily | 24h |
| Style | 7 days |
| Seasonal | until expiry |

> *Limits preserve anticipation.*
