# Passport: Stamps Logic

## Summary
Award a stamp on the first confirmed scan of a building. Variants may exist later (quest, seasonal), but V1 uses a single regular variant.

## Rules
- One stamp per building per user
- Extra XP multiplier if the stamp occurred during an active derive
- Repeat scans: XP only, no duplicate stamp

## Data
- stamps: definitions and art assets
- passport_entries: user_id, stamp_id, acquired_at, source
