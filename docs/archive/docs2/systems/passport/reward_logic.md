# Passport Reward Logic

## Summary
Defines when users earn stamps, achievements, and micro-rewards from exploration. Keeps momentum without turning JINK into a chore chart.

## Triggers
- First-time scan: issue stamp and +25 XP.
- Walk completion: +40 XP proportional to stops.
- Diversity badge: 6+ archetypes stamped in a week → one-time badge.

## Rules
- No duplicate stamps. Repeat scans yield XP only.
- Quest variants can mint special stamp skins in future seasons.
