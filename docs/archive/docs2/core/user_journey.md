# Core: User Journey

## Summary
Describes the user’s emotional and functional arc through a typical session.

## Modes
- **Direct Scan:** spontaneous curiosity, immediate reward.
- **Derive:** planned exploration, layered discovery.
- **Reflection:** reviewing Passport, sharing memories.

## Emotional Beats
Curiosity → Recognition → Reward → Reflection → Renewal.

> *Every loop teaches the eye a new way to see.*
