# Product: MVP Roadmap

## Goal
Ship a lovable core loop: Scan → Stamp → Orb → Derive → Walk → Summary.

## Scope
- Quiz and aesthetic profile
- Scanning with CLIP + GPS
- Passport (stamps, past walks, lists)
- Derive generator with time slider
- Orb reactions tied to XP and drift

## Excluded (Post-MVP)
- Leaderboards
- Decay mechanics
- Creator tools
- Seasonal quests
