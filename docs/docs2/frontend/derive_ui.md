# Frontend: Derive UI

## Summary
UI for creating and navigating a dérive (walk). Provides temporal and aesthetic control without clutter.

## Flow
1. Set duration slider (5–90 min)
2. Toggle Personal / Random
3. Preview route on map
4. Begin walk → sequential stop cards

## Live State
- Active step index
- XP gained
- Orb response

## Design
- Minimal HUD over map
- XP and orb indicators animate softly

> *The interface should feel like weather — responsive, not forced.*
