# Contributor Guide

## Summary
Guidelines for developers, designers, and writers contributing to JINK’s documentation or codebase.

## Principles
- Keep clarity above completeness.
- Match tone — factual but inspired.
- Use relative paths for links.
- One topic per file.

## Workflow
1. Branch from `docs_update`
2. Add or edit markdowns
3. PR with clear changelog

> *Every contributor adds another layer to the city of knowledge.*
