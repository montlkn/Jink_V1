# Product: Launch Plan

## Target
Beta release with a single city focus and 100–200 prioritized buildings.

## Tracks
- Engineering: stability, crash-free sessions, latency budgets
- Content: building curation, stamp art, copy
- Growth: warm invites, tasteful social previews
- Support: in-app feedback and quick hotfix pipeline

## Success Metrics
DAU/WAU, first-week retention, average scans per session, derive start rate, stamps per active user.
