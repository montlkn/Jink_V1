# Derive: Walk UI Flow

## Summary
Simple, legible, time-first UI: slider for minutes, toggle for Personalized vs Random, and a clear start button.

## Flow
Home → Start Jink → Set time + randomness → Show preview stops → Start → In-walk: next stop card + map → Finish → Summary (stamps, XP, path drawing)

## UX Notes
- Show whether a stop matches top archetypes
- Allow “skip” without punishing XP
- End screen should surface new stamps and a thumbnail of the walk drawing
