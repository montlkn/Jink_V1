# Quests System Overview

## Summary
Quests are optional guided objectives that add rhythm and surprise to the experience. They build habits around scanning and dérives without enforcing grind.

## Structure
Each quest has: title, description, type, requirements, xp_reward, and expiry.

## Types
- Daily: short-term curiosity tasks
- Thematic: style or location-based
- Seasonal: time-limited challenges

## UX
Subtle reminders, progress feedback, completion flair.

> *Quests are poetry in disguise of objectives.*
